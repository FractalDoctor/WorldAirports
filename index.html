WORLD AIRPORTS

Global Airport Reference for iOS

Explore over 9,300 airports, aerodromes and airfields worldwide with a cockpit-inspired interface built for pilots and aviation enthusiasts. Search instantly by name, city, country, ICAO or IATA code. View runway details, radio frequencies, interactive maps and more — all offline, no internet required.

FEATURES

  • Over 9,300 airports with ICAO and IATA codes
  • Runway data for 7,600+ airports — designators, dimensions, surface, lighting
  • Radio frequencies for 5,700+ airports — ATIS, TWR, GND, APP and more
  • Instant universal search across all fields
  • Interactive maps with Standard and Satellite views
  • Country flags, municipalities, altitude and coordinates
  • Dark cockpit-themed UI with amber and green instrument colours
  • All data bundled — works completely offline
  • No accounts, no tracking, no ads
